# Release Notes — v1.1.0

## Added
- Додано спеціальний базовий тариф доставки `80.0` для міста `"Kyiv"` (для `"Ivano-Frankivsk"` збережено `50.0`, для інших міст — `110.0`).
- Додано явний параметр ставки податку `tax_rate` (зі значенням за замовчуванням `0.20`) у функцію `process_standard_invoice`.
- Виділено окремі спеціалізовані функції `process_standard_invoice` та `process_tax_exempt_invoice` для різних сценаріїв виставлення рахунків.

## Changed
- Збільшено коефіцієнт вартості доставки за вагу з `12.0` до `15.0` за кілограм.
- Виконано повний архітектурний рефакторинг модуля `billing.py`: здійснено перехід від високої зв'язності (Common, Stamp та Control Coupling) до еталонної зв'язності за даними (Data Coupling).

## Breaking Changes
- Змінено сигнатури функцій розрахунку вартості доставки та виставлення рахунків: замість передачі об'єкта `CustomerProfile` функції тепер приймають виключно примітивні типи даних (`city: str`, `weight_kg: float`).
- Видалено глобальну змінну стану `GLOBAL_TAX_RATE`.
- Видалено монолітну функцію `process_invoice` разом із керуючим числовим прапорцем `mode_flag`.
